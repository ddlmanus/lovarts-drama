# 更新说明

更新时间：2026-05-23

本次更新主要围绕平台首页、AI 短剧流程、模型选择、用户积分、系统奖励配置和 MySQL 兼容问题进行调整，目标是让普通用户进入网站和使用短剧功能时更顺畅，不再因为管理员配置接口或旧模型配置导致异常。

## 首页与导航

- 网站默认入口调整为首页内容，访问根路径时直接展示首页。
- AI 短剧保留为独立入口，点击左侧导航的“AI短剧”会进入短剧列表，不会再错误跳回首页。
- 首页路由保持为根路径，不再额外使用 `/home`。
- 短剧编辑页已回到系统主布局中打开，左侧导航保持可见，不再全屏覆盖。
- 短剧编辑页顶部流程栏调整为和左侧导航一致的深色面板效果，视觉风格更统一。

## 模型选择与未登录体验

- 未登录用户访问首页和创作相关页面时，会优先加载平台可用模型，避免一进入网站就长时间加载或请求失败。
- 登录用户会同时看到自己的模型和平台模型，短剧创建、分集编辑、图片生成、视频生成、音频相关选择都统一使用这套模型来源。
- 短剧流程中移除了对旧模型配置的依赖，普通用户不再因为访问管理员模型配置而出现权限错误。
- 文本、图片、视频、音频模型下拉选择已统一调整，新增分集和分集制作时会使用当前可用模型。

## AI 短剧流程

- 新增分集时，图片、视频、音频配置会从用户和平台模型中选择。
- 分集详情页中的分镜、角色、场景、制作、作品流程继续保留，并和系统主界面保持一致。
- 分镜拆解时会使用当前选择的视频模型信息，生成更匹配所选模型的提示内容。
- 分集页显示的积分已改为当前登录用户的真实积分，不再显示固定数值。
- 用户积分变化后，分集页会跟随刷新，方便用户看到扣费、充值或赠送后的余额变化。

## 音色与语音

- 普通用户现在可以获取可用音色列表，不再需要管理员权限。
- 音色同步仍然保留为管理操作，避免普通用户误触发后台同步。
- 音色查询补齐了 MySQL 兼容处理，避免音色列表加载异常。

## 系统奖励设置

- 系统设置中新增奖励积分配置项。
- 管理员可以设置每天登录赠送多少积分。
- 管理员可以设置用户注册赠送多少积分。
- 管理员可以设置每邀请一名新用户赠送多少积分。
- 用户注册、登录和邀请奖励会根据系统配置发放，并同步更新用户积分。

## 角色库、场景库和短剧数据

- 角色库和场景库修复了 MySQL 迁移后的查询兼容问题。
- 短剧、分集、分镜、合成、拼接、任务和相关数据读取流程补齐了 MySQL 兼容处理。
- 修复了部分列表查询、筛选、排序和详情查询在 MySQL 环境下可能报错的问题。
- 修复了短剧创建后进入详情时可能因为参数异常导致服务中断的问题。

## 管理与权限

- 管理员专用配置仍保留管理员权限。
- 普通用户创作所需的模型、平台模型、音色等基础能力已拆分出来，不再误走管理员权限。
- 系统设置、后台模型管理、旧配置管理仍属于后台管理范围。

## 用户体验

- 未登录访问首页时不再直接触发需要登录的模型请求。
- 短剧页面打开后左侧导航保持一致，用户不会失去系统导航。
- 短剧编辑页顶部区域、任务入口、积分展示和模型选择体验更统一。
- 真实积分展示减少误解，用户能看到当前账号余额。
- 多处接口异常和数据库兼容问题已修复，短剧相关页面稳定性提升。

## 验证情况

- 前端构建已通过。
- 后端类型检查已通过。
- 短剧页面中旧管理员模型配置请求已移除。
- 音色列表权限已调整为普通用户可访问。
