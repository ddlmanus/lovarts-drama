# 更新说明

更新时间：2026-05-23

本次更新围绕 AI 短剧创作流程、专业 Agent 制作体系、角色库与场景库、模型配置、积分展示、图片任务同步和整体创作体验进行升级，让用户在创建短剧、生成角色形象、制作场景图、拆解分镜和批量生成素材时获得更统一、更专业、更清晰的体验。

## AI 短剧创作流程

- 短剧创建流程已根据用户选择的类型和风格进行统一约束。
- 剧本、角色、场景、分镜、图片和视频制作会围绕同一项目风格保持一致。
- 用户选择 3D 动画、动漫、漫剧等不同风格后，系统会使用对应方向的专业制作要求。
- 剧本内容、角色形象、场景画面和分镜脚本会共同遵循项目风格，减少风格漂移。
- 下一步流程保持在新版短剧创作页面中完成，流程衔接更加连贯。

## 专业 Agent 能力

- 短剧制作流程接入更专业的 Agent 制作约束。
- 剧本改写新增“Agent 改写”入口，用户可以输入原始想法或文本，由 Agent 根据所选类型和风格改写成更专业的短剧剧本。
- 剧本改写会按照资深导演级创作标准组织剧情、节奏、人物行动、情绪推进和画面表达。
- 分镜提取升级为商业级分镜制作方向，根据用户选择的短剧类型和风格输出匹配的分镜脚本。
- 分镜脚本会服务于后续图片、视频、配音、音效和合成流程，便于直接进入制作阶段。

## 角色库与场景库

- 角色库定位为用户自己的公共角色素材库。
- 新增角色库素材时不再要求绑定剧本。
- 场景库定位为用户自己的公共场景素材库。
- 新增场景库素材时不再要求绑定剧本。
- 用户上传到角色库和场景库的图片，可以在创建短剧、选择角色图或选择场景图时复用。
- 角色库和场景库的新增弹框与短剧创作中的新增角色、场景弹框保持一致，包括尺寸、布局和交互体验。

## 角色与场景生成

- “一键生成形象”会结合剧本中的角色描述和项目风格类型生成。
- 角色图片生成会遵循角色身份、外貌、服装、气质和剧情设定。
- 场景图片生成会遵循剧本场景描述、时代环境、空间氛围和项目风格。
- 角色图、场景图和分镜图之间会保持统一的风格方向。

## 分镜素材生成

- 分镜图片生成支持按用户选择的素材类型执行。
- 用户选择关键帧、首帧、尾帧或动作序列时，系统会按所选类型生成对应素材。
- 批量生成会为分镜脚本批量创建生成任务。
- 生成中的任务会在界面展示生成状态。
- 生成完成后，素材会回填到对应分镜卡片中。
- 已有角色图和场景图会作为分镜素材制作的重要参考，帮助分镜画面延续角色与场景一致性。

## 图片任务同步

- 图片任务列表会同步平台任务状态。
- 平台侧完成的图片任务会自动下载图片并写入本地任务记录。
- 分镜关键帧完成后会回填到对应分镜脚本卡片。
- 任务状态会根据平台结果展示为进行中、已完成或失败。
- APIMart 图片尺寸会自动处理为平台支持的规格，提升图片任务提交兼容性。

## 模型与供应商配置

- OpenAI 兼容类型和 Google 相关供应商支持填写 Base URL。
- 其他供应商保持固定平台配置，减少用户误填中转地址带来的使用偏差。
- 图片、视频、音频、文本模型选择继续按用户配置和平台模型统一展示。
- 生成流程会根据当前选择的模型和配置动态计算展示信息。

## 积分展示与消耗预估

- 顶部积分展示使用当前登录用户的真实总积分。
- 短剧页面会从用户信息接口读取积分余额。
- 图片生成消耗会根据所选模型、分辨率和生成数量动态计算。
- 使用用户自有 API 模型时，不展示平台积分消耗。
- 使用平台或官网模型时，会按照后台配置的模型计费规则展示预计消耗。
- 批量生成会根据需要生成的图片总数和分辨率计算预计积分。

## 页面体验

- 顶部任务入口、积分展示和操作按钮布局进行了整理。
- 任务入口在不同宽度下保持清晰展示。
- 图片生成、批量生成、任务状态和素材回填的界面反馈更加明确。
- 加载状态和按钮状态保持一致，用户可以清楚看到当前正在执行的制作流程。

- 图片任务同步已通过本地接口验证。
- 分镜关键帧任务已完成回填验证。
- 任务列表状态展示已完成验证。
